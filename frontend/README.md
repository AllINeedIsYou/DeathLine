# DeathLine — frontend

React + TypeScript + Vite. Согласованный интерфейс входа, регистрации, кабинетов сотрудника и администратора, задач (таблица/доска), анкет, приглашений и GOAT.

## Запуск

Нужны Node.js 22+ и npm.

```sh
npm install
npm run dev
```

Адрес локального сервера: http://localhost:5173. Для сборки: `npm run build`; результат — `dist/`. Для просмотра сборки: `npm run preview`.

## Страницы

- `/` — вход.
- `/register/` — регистрация.
- `/invite/<token>` — приглашение.
- `/admin/` — интерфейс администратора.
- `/employee/` — интерфейс сотрудника.

Старые адреса с `-preview` оставлены совместимыми для уже открытых вкладок, но показывают тот же очищенный интерфейс. Переключателя ролей и прямых обходных входов в форме регистрации нет.

## Текущее состояние

Вымышленные сотрудники, задачи, рейтинги, приглашения, демонстрационные аккаунты и служебные плашки удалены. Все кабинеты начинают пустыми. Старое бизнес-хранилище localStorage не читается и не изменяется. Локально сохраняется только выбор визуальных глитчей.

Это готовый к подключению **интерфейс**, пока без серверной интеграции. Вход, регистрация, подтверждение почты, приглашения, сохранение задач/анкет/заметок и завершение задач ещё требуют API. До подключения серверных операций интерфейс показывает ошибку доступности вместо фиктивного успеха. Открытые адреса кабинетов позволяют увидеть пустую вёрстку; они не создают сессию и не являются защитой доступа.

Код бэкенда не изменён. Для настоящей работы нужны сессия, проверка прав и данные сервера. В проекте нет паролей, ключей, `.env`, базы данных или учётных записей.

## Подключение по частям

Начать с [плана бэкенда](docs/BACKEND_NEXT_STEPS.md). Поля, маршруты и примеры JSON — в [предложении контракта API](docs/API_CONTRACT.md). Это предложение, не уже реализованное API.

Границы подключения:
- `src/features/auth/AuthScreen.tsx` — вход.
- `src/features/auth/JoinScreen.tsx` — регистрация, подтверждение почты и вступление.
- `src/features/auth/invitations.ts` — загрузка и действия приглашений/команд.
- `src/features/data/team-data.ts` — загрузка задач и сотрудников, изменения, выполнение и личные заметки.
- `src/features/employee/EmployeePage.tsx` — передача текущего участника и его задач в кабинет.
- `src/App.tsx` — маршрутизация; после подключения `/auth/me` добавить проверку сессии и роли.

Сейчас границы данных возвращают пустые списки, а неподключённые операции явно завершаются ошибкой. Во время интеграции их нужно заменить асинхронными запросами с состояниями загрузки/ошибки и обновлением данных после успешного ответа. Фронт не отправляет запросы к выдуманным endpoints.

## Что сохранено в оформлении

Тёмная палитра, логотип, иллюстрация, таймер 15 минут с добавлением времени, эффект «мёртвого» экрана на нуле. Иконка смерти на входе/регистрации переключает глитчи с подписью на 5 секунд. В кабинетах логотип открывает собственную главную. Всплывающие уведомления закрываются через 10 секунд.

Исходники — `src/`, изображения — `public/brand/`. На хостинге для прямых адресов нужна выдача `index.html` для маршрутов приложения. `dist/` — только статические файлы, без API.
